# Prueba de Kibotos para Mac

¡Gracias por probarlo! No hace falta saber programar. Sigue los pasos en orden y marca cada uno con ✅ (funciona) o ❌ (falla).

**Si algo falla o aparece un mensaje de error:** haz una captura de pantalla (teclas **⌘ Cmd + ⇧ Mayús + 4** y arrastra sobre la zona, o **⌘ + ⇧ + 3** para toda la pantalla; la imagen aparece en el Escritorio) y envíala junto con el número del paso.

Anota también tu modelo de Mac y la versión de macOS ( menú  › *Acerca de este Mac*).

## Preparación

Necesitas unos archivos de prueba. Lo más fácil es pedírselos a quien te envió Kibotos, o usar estos:

- Un **.zip** cualquiera (por ejemplo, selecciona una carpeta en Finder › clic derecho › *Comprimir*).
- Un **.rar** (te lo puede enviar quien te pasó Kibotos).
- Un **archivo con contraseña** (un .zip o .7z protegido; pide uno y su contraseña).

## Pasos

| # | Qué hacer | Qué debería pasar | ✅ / ❌ |
|---|-----------|-------------------|--------|
| 1 | Abre el archivo `kibotos-mac-v0.1.dmg`. Arrastra **Kibotos** a la carpeta **Applications** (Aplicaciones). | Se copia sin errores. | |
| 2 | Abre Kibotos desde *Aplicaciones*. macOS dirá que no puede verificarlo: pulsa **Hecho**. Ve a  › *Ajustes del Sistema* › *Privacidad y seguridad*, baja hasta el aviso de Kibotos y pulsa **Abrir igualmente**. Confirma con tu contraseña. | Se abre la ventana de Kibotos. Las siguientes veces se abre directamente. | |
| 3 | En Kibotos: menú *File › Open…* (o **⌘ + O**) y elige el **.zip**. | Se ve la lista de archivos y, a la izquierda, las carpetas. | |
| 4 | Haz doble clic en una carpeta de la lista y luego pulsa la tecla **⌫ Borrar** (o **⌘ + ↑**). | Entra en la carpeta y luego vuelve atrás. | |
| 5 | Haz doble clic en un archivo de la lista (una foto o un texto). | Se abre con su programa habitual (Vista Previa, TextEdit…). | |
| 6 | Pulsa **Extract All…** (o **⌘ + E**) y elige el Escritorio. | Aparece una barra de progreso y luego un aviso de que terminó. **Show in Finder** muestra los archivos. | |
| 7 | Vuelve a extraer en el mismo sitio (paso 6 otra vez). | Pregunta si quieres reemplazar los archivos que ya existen. | |
| 8 | Abre el **.rar** (⌘ + O). Selecciona un solo archivo de la lista y pulsa **Extract Selected…** | Se abre bien y extrae solo ese archivo. | |
| 9 | Abre el **archivo con contraseña**. | Pide la contraseña. Con una contraseña incorrecta avisa y deja volver a intentarlo; con la correcta abre o extrae. | |
| 10 | Pulsa **New Archive…** (o **⌘ + N**), elige una carpeta con algunos archivos, en *Format* elige **7z** y pulsa **Create…**. Guárdalo en el Escritorio. | Se crea un archivo `.7z`. Ábrelo con Kibotos para ver que contiene lo mismo. | |
| 11 | Cierra Kibotos (**⌘ + Q**). En Finder, haz doble clic en el **.zip** del paso 3… si se abre con otro programa, usa clic derecho › *Abrir con* › **Kibotos**. | Kibotos se abre mostrando ese archivo. | |
| 12 | Con Kibotos abierto, **arrastra un archivo .zip desde Finder** a la ventana. | Se abre ese archivo. | |
| 13 | Arrastra **varias fotos o documentos** desde Finder a la ventana de Kibotos. | Aparece la ventana *New Archive* con esos archivos, lista para crear un archivo comprimido. | |
| 14 | Con un archivo abierto, **arrastra un elemento de la lista al Escritorio**. | El archivo aparece en el Escritorio. | |
| 15 | Arrastra un .zip **sobre el icono de Kibotos en el Dock**. | Kibotos lo abre. | |
| 16 | Cambia el aspecto del Mac entre claro y oscuro ( › *Ajustes del Sistema* › *Apariencia*). | Kibotos cambia de colores con el sistema. | |
| 17 | Menú *Kibotos › About Kibotos*. | Muestra la versión y la firma «byarcy 2026». | |
